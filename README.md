# Hilas — ἱλαστήριον · ἱλασμός · ἱλάσκομαι

Projeto de pesquisa exegética e lexicográfica sobre o grupo de palavras
gregas que o Novo Testamento usa para a obra de Cristo em relação ao
pecado e à ira de Deus — tradicionalmente traduzido "propiciação", em
disputa desde C. H. Dodd (1931, 1935) até a resposta clássica de Leon
Morris e Roger Nicole (1955).

**Comece por `CLAUDE.md`** — é o mapa de tudo. Em seguida:

- `ESCOPO_HILAS.md` — delimitação do recorte, os três lexemas, os eixos de decisão.
- `ANATOMIA_DO_MOLDE.md` — o que este projeto herdou de um método mais amplo, e por quê.
- `_artifacts/sentinelas_HILAS.md` — as armadilhas factuais deste tema, algumas já com evidência de outro projeto anexada.
- `_scripts/` — automação local (busca em grego tolerante a Unicode, verificação de sentinelas, dossiê de fontes).
- `FASE_0_CHECKLIST.md` e `MEMORIA_PROJETO.md` — por onde retomar.

```bash
python3 _scripts/checagem_retomada.py
```
